# SongLang 🎵

Learn languages through the power of music. An innovative application by Emarov that uses YouTube songs to create an immersive and fun learning experience.

## Core Features

*   **Multi-Language Support:** Start with Arabic, English, Russian, and Spanish.
*   **Curated Playlists:** Hand-picked songs organized by language, genre, and difficulty.
*   **Interactive Learning:**
    *   Synchronized lyrics (Karaoke-style).
    *   Instant translation and word definitions.
    *   Interactive games (fill in the blanks, sentence translation).
*   **Precise Pronunciation Feedback:** Advanced speech analysis to ensure users don't pass until their pronunciation is correct.
*   **Progress Tracking:** A personalized dashboard to monitor learned vocabulary and achievements.

## Tech Stack

*   **Mobile App:** React Native
*   **Backend:** Node.js (Express.js)
*   **Database:** PostgreSQL
*   **APIs:**
    *   YouTube Data API
    *   Google Cloud Speech-to-Text
    *   Google Cloud Translation
